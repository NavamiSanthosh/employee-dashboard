Employee Dashboard

Project Description

Employee Dashboard is a web application developed using React to display employee information in an organized interface.

Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite

Features

- Display employee information
- View employee details
- Navigate between pages

How to Run

1. Install Node.js.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run "npm install".
5. Run "npm run dev".
6. Open the local URL displayed in the terminal.
